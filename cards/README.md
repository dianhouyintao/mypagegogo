# cards/ 卡片起草区

发文流程：**你只写卡片和拼接初稿，其余交给「发文」skill。**

- **卡片**：写进当月文件夹（如 `2026-11/`），一张卡一个 md 文件，文件名随意（建议 `主题关键词.md`），内容自由写——一段想法、一则笔记、一个片段都行。
- **拼接初稿**：`draft.md`（在 cards/ 根目录）里写本次文章的拼接顺序和段落草稿——哪些卡片按什么顺序、每段大概说什么、开头结尾怎么写，格式不限。
- **发布**：对我说「发文」即可。我会拼接 → 中度润色（改动列清单给你确认）→ 落稿 posts/ → 构建网站 → 本地 git 提交。
- **归档**：发布后用过的卡片移入 `done/`（按发布批次建子目录），draft.md 清空，当月文件夹继续用。

月份文件夹到月底不用手动建，发文时发现当月文件夹不存在会自动创建。
